# TradeCat Pro 前端仪表盘

TradeCat Pro 是一个专业的加密货币技术分析 Web 界面，提供实时 K 线图表、38 个技术指标、期货数据可视化和交易信号监控。

## 🚀 快速开始

### 环境要求
- 现代浏览器（Chrome/Firefox/Edge）
- 支持 ES6+ 和 CSS3
- 屏幕分辨率建议 1280x720 以上

### 启动方式

#### 方式 1：服务器直接启动（推荐）
```bash
cd /home/siyuan/tradecat/frontend
python3 -m http.server 3000
```
访问：`http://服务器IP:3000/dashboard.html`

#### 方式 2：SSH 隧道（本地开发）
在本地 WSL2/终端运行：
```bash
# 建立 SSH 隧道
ssh -L 3000:localhost:3000 -L 8088:localhost:8088 -N siyuan@服务器IP

# 浏览器访问
http://localhost:3000/dashboard.html
```

## 📊 功能特性

### 1. 多币种 K 线图表
- 支持 BTC/ETH/BNB/SOL 四大主流币种
- 多周期切换：1m/5m/15m/1h/4h/1d
- 时间范围选择：7天/30天/90天历史数据
- TradingView 风格的专业图表

### 2. 38 个技术指标
按三类分组展示：

**📊 基础指标**
- 布林带、KDJ、MACD、OBV
- 成交量比率、RSI 谐波

**🔥 期货指标**
- 持仓量、资金费率
- 多空比、主动买卖比

**🚀 高级指标**
- ATR、CVD、VWAP、EMA
- K线形态、SuperTrend
- 流动性、趋势线等

### 3. 期货数据可视化
- 持仓量历史趋势图
- 资金费率变化图
- 使用 Chart.js 绘制

### 4. 实时交易信号
- 信号冷却状态监控
- 新信号弹窗提醒
- 信号历史记录

### 5. 数据实时性
- 每 30 秒自动刷新
- 数据时间戳显示
- 新鲜度指示器（实时/延迟/过期）

## 🔧 技术栈

- **K线图表**: [lightweight-charts](https://github.com/tradingview/lightweight-charts)
- **期货图表**: [Chart.js](https://www.chartjs.org/)
- **HTTP 客户端**: 原生 Fetch API
- **样式**: 原生 CSS3（深色主题）
- **图标**: Emoji

## 📡 API 接口

前端调用 TradeCat API 服务（端口 8088）：

| 端点 | 描述 |
|------|------|
| `GET /api/futures/ohlc/history` | K线历史数据 |
| `GET /api/indicator/snapshot` | 完整指标快照 |
| `GET /api/futures/base-data` | 基础数据（价格/成交量） |
| `GET /api/signal/cooldown` | 信号冷却状态 |

## 🎨 界面说明

### 顶部控制栏
- **币种选择器**: 切换 BTC/ETH/BNB/SOL
- **周期选择器**: 切换 K线周期
- **时间范围**: 选择历史数据天数
- **刷新按钮**: 手动刷新数据
- **状态指示**: 显示数据实时性和更新时间

### 主图表区
- **K线图表**: 左侧主区域显示价格走势
- **币种列表**: 右侧快速切换币种

### 标签页
1. **📊 技术指标**: 38 个指标按分类展示
2. **📉 期货数据**: 持仓量和资金费率图表
3. **🚨 交易信号**: 信号冷却状态和历史
4. **📋 原始数据**: K线原始数据表格

### 指标面板
- 可折叠的分组面板
- 实时数值和买卖信号
- 悬停显示详细信息

## 🐛 故障排除

### 页面显示空白
检查 API 服务是否运行：
```bash
curl http://localhost:8088/api/health
```

### 数据不更新
1. 检查网络连接
2. 查看浏览器控制台错误
3. 手动点击刷新按钮

### 图表显示异常
- 清除浏览器缓存
- 刷新页面重试
- 检查屏幕分辨率
