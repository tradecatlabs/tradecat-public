## ADDED Requirements

### 需求：数据时间戳必须显示
系统必须在所有数据展示区域显示数据的时间戳，让用户了解数据的实时性。

#### 场景：K线图表显示时间戳
- **当** 用户查看 K线图表时
- **那么** 图表必须显示最后数据点的更新时间
- **并且** 显示数据新鲜度状态（实时/延迟/过期）

#### 场景：指标卡片显示时间戳
- **当** 用户查看技术指标时
- **那么** 每个指标卡片必须显示该指标的计算时间

### 需求：必须展示全部 38 个技术指标
系统必须展示 SQLite 数据库中的所有 38 个技术指标，按类别分组显示。

#### 场景：查看基础指标
- **当** 用户展开"基础指标"面板
- **那么** 系统必须显示：MACD、KDJ、RSI、布林带、成交量、支撑阻力等基础指标

#### 场景：查看期货指标
- **当** 用户展开"期货指标"面板
- **那么** 系统必须显示：持仓量、资金费率、多空比、主动买卖比等期货相关指标

#### 场景：查看高级指标
- **当** 用户展开"高级指标"面板
- **那么** 系统必须显示：ATR、CVD、VWAP、EMA、K线形态、流动性等高级指标

#### 场景：多周期指标对比
- **当** 用户选择某个周期（如 1h）
- **那么** 所有指标必须显示该周期下的数值
- **并且** 支持快速切换周期查看不同数值

### 需求：期货数据历史图表
系统必须使用 Chart.js 展示持仓量和资金费率的历史趋势图表。

#### 场景：查看持仓量趋势
- **当** 用户切换到"期货图表"标签
- **那么** 系统必须显示近 30 天的持仓量变化曲线
- **并且** 支持缩放查看特定时间段

#### 场景：查看资金费率趋势
- **当** 用户查看期货图表时
- **那么** 系统必须显示资金费率历史变化
- **并且** 用不同颜色标记正负费率

### 需求：系统必须支持近一个月历史数据
系统必须默认加载并展示近 30 天的历史数据，并且必须支持时间范围选择。

#### 场景：默认加载 30 天数据
- **当** 用户打开页面或切换币种
- **那么** K线图表默认加载近 30 天的历史数据（约 8640 条 5分钟 K线）

#### 场景：缩放查看特定时间
- **当** 用户在 K线图表上缩放
- **那么** 图表必须显示对应时间段的详细数据
- **并且** 指标数据同步更新为该时间段的最新值

### 需求：实时交易信号展示
系统必须从 `/api/signal/cooldown` 获取并展示交易信号。

#### 场景：查看信号冷却状态
- **当** 用户切换到"交易信号"标签
- **那么** 系统必须显示当前所有信号的冷却状态
- **并且** 显示信号触发时间和过期时间

#### 场景：实时刷新信号
- **当** 系统每 30 秒自动刷新时
- **那么** 信号面板必须更新为最新状态

### 需求：前端性能优化
系统必须在展示 38 个指标时保持流畅的用户体验。

#### 场景：加载大量指标
- **当** 用户展开所有指标面板时
- **那么** 页面必须保持响应，不卡顿
- **并且** 指标卡片按需渲染，不一次性加载所有

#### 场景：快速切换币种
- **当** 用户切换币种时
- **那么** 新数据必须在 3 秒内加载完成
- **并且** 显示加载状态指示器
